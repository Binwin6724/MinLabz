# MinLabz

The website for MinLabz apps: **MinTransfer**, **MinSoundFX**, **MinDesk** and **MinPoint**.

**Live site:** https://binwin6724.github.io/MinLabz/

- Three.js 3D hero (drag to spin, click an app tile to jump to it)
- Screenshot galleries for each app
- Download buttons pulled live from each repo's latest GitHub release, with the visitor's OS pre-selected

Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages from `main`.

Run locally:

```bash
python3 -m http.server 8000
```
